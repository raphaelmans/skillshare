# Route messages to Jobs and end in a Relay

paper-design picks one of nine Jobs (Sketch, Check-structure, Set-up, Size-up, Design, Reconcile, Compare, Build, Write-up) from what the message asks for; old slice names survive only as shortcuts, and choosing a Job never grants a Gate. Jobs that end in another skill (`/to-spec`, `/to-tickets`, `/implement`, `/implement-spec`) end in a Relay: paper-design leaves the evidence in the conversation and names the command for the user to type. Those skills disable model invocation on purpose, and keeping them user-triggered keeps the user in control of what gets published to the tracker or built. As a result paper-design no longer carries its own implementation, TDD, commit, or verification logic. Amends ADR 0012 and replaces the code-delegation half of ADR 0003.
