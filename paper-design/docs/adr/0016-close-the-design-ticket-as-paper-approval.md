# Close the Design Ticket as Paper Approval

Paper Approval used to live only in the conversation, granted by an explicit `implement` request, so it was lost when the session ended. Now paper-design adds a human-in-the-loop "Design in Paper" ticket that blocks every UI ticket of a spec once `/to-tickets` has made them, and closing that ticket is Paper Approval. Build stops while it is open, Design and Reconcile warn and ask for it to be reopened before changing approved surfaces, and `/implement-spec` naturally holds UI tickets off its frontier until design is signed off. Amends ADR 0003: the words "build it" now pick the Build Job but no longer approve the design. paper-design creates the ticket itself rather than changing `/to-tickets`: it is the wrapper layer over the upstream skills, which stay unmodified.
