# Notion me

Start or continue [chief-of-staff](../chief-of-staff/SKILL.md) with Raphael’s full request. Its setup reads and owner handoffs stay on the same route.

When Notion supplies only a source or template, keep the task read-only in Notion. Deliver the result in chat unless Raphael named another destination.

For a requested write, reuse the owner’s destination. If placement is unresolved, check the relevant project or collection for an existing document or a parent for a new one. Ask Raphael before writing if placement remains unclear.

Update the identified page or supply the resolved parent page or data source when creating one. Use a standalone private draft only when Raphael or the route specifies one. Verify placement from the write response, fetching the page only if needed.
