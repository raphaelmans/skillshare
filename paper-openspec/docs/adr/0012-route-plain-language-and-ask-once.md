# Route plain-language invocations and ask for each approval once

Arguments that are neither a slice name nor an existing change directory are read as requests and routed by intent: draft or preview to `explore`, apply or build to `implement`, and a bare "accept" or "approve" to the gate pending in the conversation. A design invocation made after a displayed scope report is Scope Approval for it, approval of displayed gap corrections covers the scope as corrected unless the rerun changes route, pages, or sequence, and a design request with no change creates the change and stops once at Scope Approval. The Paper connection is checked before any report or approval request. This narrows ADR 0003 and ADR 0004 without removing their gates: production code still needs explicit words asking for it, and canonical design still needs one Scope Approval; what goes away is the second and third stop for a decision the user already made.
