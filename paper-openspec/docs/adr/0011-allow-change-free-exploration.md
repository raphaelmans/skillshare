# Allow change-free exploration on Exceptional Pages

`paper-openspec explore` draws drafts, wireframes, content previews, variant comparisons, hi-fi concepts, and journey walkthroughs from an Exploration Brief without an OpenSpec Change or Scope Approval. Each exploration gets its own `Exploration / <Name>` page, stays inside the established design system, uses real content only, and removes nothing the brief did not name; it stays out of the manifest inventory and never authorizes code. Observed use showed drafts being requested before any change existed, and the skill either stopping for a 4/4 artifact set or being bypassed entirely, which produced off-system variants, placeholder content, and rounds mixed onto one page. Building an exploration goes through Promotion: the change is created from it, scope is approved once, and nodes are copied into canonical owner pages, so ADR 0004 still governs canonical design.
