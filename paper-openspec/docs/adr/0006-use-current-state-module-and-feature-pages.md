# Use current-state module and feature pages

Paper holds the latest approved design on human-named module and feature pages instead of preserving one page per OpenSpec change: module-owned canonical components are colocated on `<Module> / Components`, cross-module components on `Shared / Components`, and screens on `<Module> / <Feature>`. OpenSpec and repository history retain change history, trading old Paper screen versions for clearer human review, canonical reuse, and stable page ownership.
