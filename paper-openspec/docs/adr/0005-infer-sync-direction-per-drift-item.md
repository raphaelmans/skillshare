# Infer sync direction per drift item

`paper-openspec sync` does not require a `to-paper` or `from-paper` argument. It begins only after explicit sync intent, may reuse fresh evidence from read-only parity, and infers direction independently for each drift item from OpenSpec ownership and Paper evidence; mixed-direction runs are valid, Paper-only behavior remains a proposal until approved, and unresolved provenance stops reconciliation. An approved plan routes Paper work through components and screens and routes code work through the existing implementation workflow.
