# Keep Paper Initialization independent and read-only

`paper-openspec init` is a project-level operation that requires the root `openspec/` directory and an explicit Paper link but no active or planning-complete OpenSpec Change; it reads Paper, artifacts, and code while mutating only root `PAPER.md`. It scans the complete Paper page tree once, reads deeply only within current-state component and feature pages, and avoids screenshots or computed-style inspection unless needed to disambiguate structure. A Manifest Refresh preserves confirmed valid entries, removes only surfaces proven absent, and stops for migration approval on malformed or unsupported schemas; an empty canonical inventory still produces a valid minimal manifest, while noncanonical or misplaced surfaces are reported as Paper Lint findings and excluded rather than repaired. Completion reports the target, inventory counts, retained, added, and removed entries, lint exclusions, and migration or freshness issues without issuing a Design Alignment or parity verdict.
