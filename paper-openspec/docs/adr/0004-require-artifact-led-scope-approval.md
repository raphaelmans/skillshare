# Require artifact-led scope approval before Paper design

Before any Paper design mutation, `paper-openspec` classifies the planning-complete change from Surface Change through User Flow, User Journey, and Product Overhaul, reports a chat-only matrix and ordered design sequence, and waits for Scope Approval. OpenSpec owns intended scope while Paper and code supply current-state evidence; this boundary prevents both isolated-screen design without journey context and full-product audits for localized changes.
